The dashboard is the auth'd control center. Once a user signs in, they land on
an overview of their organization.

## Routes

- `/` — an overview page greeting the user by name with placeholder stat cards.
- `/settings` — profile settings backed by the `profiles` table.
- `/login` and `/register` — Keycloak-hosted flows (the pages just redirect to
  Keycloak).
- `/auth/login`, `/auth/callback`, `/auth/logout` — the OpenID Connect flow.

## Auth flow

The dashboard relies on `@repo/auth`, which exposes two entry points:

- `@repo/auth/server` — PKCE login/logout URLs, code exchange, `getSession()`,
  `requireUser()`.
- `@repo/auth/edge` — `isAuthenticated()` for the route guard.

The `proxy.ts` file verifies the signed session cookie and guards the whole app,
while `app/(dashboard)/layout.tsx` re-validates the session server-side and
redirects unauthenticated visitors to `/login`. Signing out posts to
`/auth/logout`, which clears the cookie and ends the Keycloak SSO session.

## Forms

The profile form is built with **React Hook Form** and **Zod**, sharing schemas
from `@repo/validation`. Login and registration are handled entirely by
Keycloak's hosted pages.
