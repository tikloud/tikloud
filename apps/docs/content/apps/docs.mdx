The docs app is the internal documentation site you're reading right now. It
has **no backend dependency** — content is static Markdown + MDX rendered at
build time.

## How it works

Content lives as `.mdx` files under `apps/docs/content/<section>/`. A server-only
loader (`lib/content.ts`) reads those files, parses their frontmatter, and
builds the navigation tree — so the sidebar, breadcrumbs, and prev/next links
stay in sync automatically.

Pages are rendered from a single dynamic route (`app/(docs)/[...slug]/page.tsx`)
that is fully static at build time via `generateStaticParams`.

## Stack

- `next-mdx-remote-client` — compiles MDX to server components.
- `gray-matter` — frontmatter parsing.
- `remark-gfm` — GitHub-flavored Markdown (tables, strikethrough).
- `@shikijs/rehype` — syntax-highlighted code blocks.
- `rehype-slug` / `rehype-autolink-headings` — heading anchors for deep links.
