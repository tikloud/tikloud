The landing page is Ti Kloud's public face — a marketing site with a hero, a
features grid, a call-to-action, and a waitlist form.

## Structure

- `/` — the marketing page: `Navbar`, `Hero`, `Features`, `Cta`, `Footer`.
- `/waitlist` — the early-access waitlist, backed by a Supabase table.

## Waitlist

The waitlist form submits to a Supabase table via a server action
(`app/actions/waitlist.ts`). The payload is validated with a shared Zod schema
from `@repo/validation` before insert.

## Shared chrome

The page header and footer are the shared `SiteHeader` and `SiteFooter`
components from `@repo/ui`, the same ones used across the platform.

<Callout variant="warning" title="Supabase required">
  The landing page needs `NEXT_PUBLIC_SUPABASE_URL` and
  `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` in `.env.local`. Without them the
  auth middleware breaks.
</Callout>
