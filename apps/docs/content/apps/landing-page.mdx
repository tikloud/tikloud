The landing page is Ti Kloud's public face — a marketing site with a hero, a
features grid, a call-to-action, and a waitlist form.

## Structure

- `/` — the marketing page: `Navbar`, `Hero`, `Features`, `Cta`, `Footer`.
- `/waitlist` — the early-access waitlist, backed by the `waitlist` table.

## Waitlist

The waitlist form submits via a server action (`app/actions/waitlist.ts`). The
payload is validated with a shared Zod schema from `@repo/validation`, then
inserted with `insertWaitlist` from `@repo/db`. Duplicate emails map to
"You're already on the list."

## Shared chrome

The page header and footer are the shared `SiteHeader` and `SiteFooter`
components from `@repo/ui`, the same ones used across the platform.

<Callout variant="warning" title="Postgres required">
  The landing page needs `DATABASE_URL` in `.env.local` for the waitlist
  server action.
</Callout>
