Pushes to `main` (and `v*` tags) trigger the **Docker CI** workflow
(`.github/workflows/docker-ci.yml`).

## What it does

1. Builds `linux/amd64` images for all three apps via a build matrix.
2. Publishes to GitHub Container Registry (GHCR):

| Image | Tags |
| --- | --- |
| `ghcr.io/tikloud/dashboard` | `latest`, semver tags, `sha-*` |
| `ghcr.io/tikloud/landing-page` | `latest`, semver tags, `sha-*` |
| `ghcr.io/tikloud/docs` | `latest`, semver tags, `sha-*` |

## Secrets

No secrets are required at build time — Keycloak and Postgres credentials are
runtime environment variables injected by the Helm chart at deploy time.

## Caching

Builds use the GitHub Actions cache (`type=gha`) for both layers and registry
cache to keep image builds fast across pushes.
