Every app ships as a Docker image built from the root `Dockerfile` via a
**build target**, using Next.js standalone output for lean production images.

## Images and targets

| Image | Build target | Port |
| --- | --- | --- |
| `tikloud/dashboard` | `runner-dashboard` | 3000 |
| `tikloud/landing-page` | `runner-landing-page` | 3001 |
| `tikloud/docs` | `runner-docs` | 3002 |

## Runtime env vars

Keycloak and Postgres credentials are **server-side runtime** variables — they
are not baked into images. Supply them to `docker run` (or via the Helm chart):

```bash
docker build --target runner-dashboard -t tikloud/dashboard .

docker run -p 3000:3000 \
  -e DATABASE_URL=postgresql://tikloud:...@host.docker.internal:5432/tikloud \
  -e KEYCLOAK_URL=http://host.docker.internal:8080 \
  -e KEYCLOAK_REALM=tikloud \
  -e KEYCLOAK_CLIENT_ID=dashboard \
  -e KEYCLOAK_CLIENT_SECRET=... \
  -e AUTH_SECRET=... \
  -e AUTH_URL=http://localhost:3000 \
  tikloud/dashboard
```

`docs` has no backend dependency and needs no environment variables.
