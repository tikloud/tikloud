## Heading

`Heading` renders an `h1`–`h6` with a consistent type scale.

```tsx
<Heading level={2}>Section title</Heading>
```

## Forms

`Input`, `Textarea`, and `Label` follow the same focus ring (`ring-brand-500`)
and support an `invalid` flag for validation errors.

```tsx
<Label htmlFor="email">Email</Label>
<Input id="email" type="email" placeholder="you@example.com" />
<Textarea placeholder="A longer response..." />
```

<Label htmlFor="email">Email</Label>
<Input id="email" type="email" placeholder="you@example.com" className="mt-2" />
<Textarea placeholder="A longer response..." className="mt-2" />

## Container, Prose, and layout

- `Container` — a `max-w-7xl` centered wrapper with responsive padding.
- `Prose` — typographic styling for rendered Markdown/MDX content (this page).
- `Toc` — the **On this page** navigation seen on wide screens.
- `SiteHeader` / `SiteFooter` — the sticky platform header and footer.
- `Sidebar` / `SidebarNav` / `SidebarNavLink` — left navigation shells (used by
  the dashboard and this site).
- `Breadcrumbs` — the breadcrumb trail at the top of each doc page.
